Privacy Policy

Last updated: November 20, 2026

This policy describes how the software behind the YouTube channel "The PC Waiting Room" (the "App") handles information. The App is a private, single-user tool run by the channel owner to publish videos to the owner's own YouTube channel.

What the App accesses

  • With the channel owner's authorization (Google OAuth), the App uses the YouTube Data API v3 to upload videos to the owner's channel, update their titles, descriptions and privacy status, and read basic information and statistics about the channel's own videos (views, likes, comment counts and the text of recent public comments on those videos).
  • With the same authorization, the App uses the YouTube Analytics API to read aggregate, anonymous reports about the channel's own videos (for example views per day, traffic sources and audience retention).

What the App does not do

  • It does not collect personal information from viewers, does not use cookies or trackers, and does not sell, share or transfer any data to third parties.
  • It does not access any YouTube account other than the channel owner's own channel.

Storage and retention

OAuth tokens and the statistics described above are stored only on the channel owner's computer, protected by file-system permissions, and are used only to operate and improve the channel. Statistics are kept while the channel is active and deleted when the project ends. The owner can revoke the App's access at any time at https://myaccount.google.com/permissions, which stops all access.

Google API Services

The App's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. By using YouTube features you are also subject to the YouTube Terms of Service and the Google Privacy Policy.
